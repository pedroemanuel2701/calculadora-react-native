# 🧮 Calculadora React Native

Este é um projeto de calculadora simples desenvolvido para fins de aprendizado sobre os fundamentos do **React Native**. O foco principal foi entender o gerenciamento de estados com Hooks, manipulação de inputs de texto e a lógica de componentes funcionais.

## 🚀 Funcionalidades

O app realiza as quatro operações matemáticas básicas:
- [x] **Soma**: Adição de dois valores decimais.
- [x] **Subtração**: Diferença entre dois valores.
- [x] **Multiplicação**: Produto de dois valores.
- [x] **Divisão**: Quociente entre dois valores.

## 🛠️ Tecnologias Utilizadas

* [React Native](https://reactnative.dev/) - Framework para desenvolvimento mobile.
* [Expo](https://expo.dev/) - Plataforma de ferramentas para React Native.
* [JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) - Linguagem base.

## 🏗️ Conceitos de Engenharia de Software Aplicados

Durante o desenvolvimento, foram aplicados conceitos fundamentais como:
* **Hooks (useState):** Gerenciamento de estado para sincronização da interface com a lógica.
* **Imutabilidade:** Uso de `setters` para atualização de dados.
* **Tratamento de Dados:** Conversão de tipos (String para Float) via `parseFloat`.
* **Componentização:** Estruturação de código em componentes funcionais.

## 📦 Como rodar o projeto

### Pré-requisitos
* Node.js instalado.
* Expo Go instalado no seu celular (opcional para teste físico).
### Via Windows ou Linux
. Instalar dependências

   ```bash
   npm install
   ```

2. iniciar Calculadora

   ```bash
   npx expo start

 2. Caso dê erro, funcionalidade para limpar cachê

   ```bash
   npx expo start -c
   ```
